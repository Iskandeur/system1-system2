System 1 / System 2: confidence-gated routing

A fast System 1 model answers first; when its confidence is below a threshold the question escalates to a stronger System 2 model. Both roles are pluggable (any OpenAI-compatible endpoint, the Anthropic API, or a TypeSafe decision model).
